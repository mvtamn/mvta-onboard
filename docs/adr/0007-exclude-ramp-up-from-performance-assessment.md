# Exclude ramp-up from Performance Assessment

OnBoard's Performance Assessment module will neither determine, represent, nor apply contractual ramp-up. Ramp-up is handled administratively outside this module, so assessment calculations, review screens, and official artifacts contain no ramp-up stage or multiplier. This deliberately gives up automated ramp-up arithmetic to prevent the system from interpreting an administrative contract decision or presenting that interpretation as part of the official assessment.
