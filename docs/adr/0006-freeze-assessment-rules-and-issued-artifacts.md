# Freeze assessment rules and issued artifacts

Each Assessment Period uses an immutable Assessment Rule Set selected for that calendar month in the `America/Chicago` timezone, and each issued Final Assessment remains immutable. Contract amendments normally take effect in a later period; correcting an issued result requires full review and a Superseding Final Assessment that preserves the prior artifact and restarts the dispute period. This favors contractual reproducibility and defensible dispute handling over silently applying current rules or editing past results.
